# make_package (Block 2)

Status: implemented 2026-10-13 (`R/MakePackage.R`, `inst/tinytest/test_make_package.R`).
Block 1 = `scalar_type_parameter.md`.

## Why

ast2ast R files -> compiled code inside an existing R package.
First use case: Thermosimfit VAPRO loss.

## API

`make_package(files, entry_points, package_dir = ".", overwrite = FALSE)`
- like `Rcpp::compileAttributes`: extends an existing package
- files relative to `package_dir`, not in `R/` (sourced at install ->
  `new_type()` fails, DSL `f` clashes with the RcppExports `f`); default
  place `inst/tools/`

## Decisions (Konrad)

- entry fns exported, all other top-level fns internal helpers
- several entry points (2026-10-13, for tsf): one translation + cpp file per
  entry; helpers per entry via call graph (`reachable_helpers`, `all.names`,
  also finds fns passed as values); types not filtered (structs are
  templates, unused ones cost nothing); helper reachable from no entry ->
  warning; generated cpp of removed entries deleted
- top-level code: only `new_type(...)` and `name <- function(...)`;
  everything else is an error with `file:line`
- types: prescan all files for top-level `new_type()`; duplicates -> error
- helpers are inserted into the entry fn after `argtypes()`/`returntype()`
  -> `translate_internally` turns them into functors, no new codegen
  ```r
  f <- function(a) {
    argtypes(...); returntype(...)
    helper <- function(...) {...}   # inserted
    <original body>
  }
  ```
- one outer fn -> single global `ETR_REAL` alias
- headers copied into `inst/include/ast2ast/` (own folder) + `LICENSE_NOTE`
- `DESCRIPTION`/`NAMESPACE`: only checked, never edited; `export()` of the
  entry points not required (tsf uses them internally)
- overwrite: files with the "Generated by" marker -> overwrite; others ->
  `askYesNo`, non-interactive -> error unless `overwrite = TRUE`

## Runtime labels

`In 'pkg: file.R:12 (fn): <statement>': <error>`
- srcrefs from `parse(text, keep.source = TRUE, srcfile = "pkg: file.R")`
- per-statement `location` field on the nodes (set in `create_ast`)
- carried through rebuilt blocks: `keep_trailing_srcrefs()`, generated
  `return()` takes the location of the replaced statement
- `translate()` strips srcrefs (`removeSource`), labels unchanged there
  (console fns would count lines from the start of the fn)
